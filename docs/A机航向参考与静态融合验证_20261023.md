## 实际采用的参考方向

用户说明没有已知动捕轴相对北向的标定。先只读同步采集动捕和 PX4：
- heading_probe_20261023T080541Z：1603对数据，候选差约-45.593774°。
- 临时测试前重新采集 heading_probe_20261023T081303Z：1586对，后1190对计算的差约 **-45.834592°**，差值标准差0.024870°、跨度0.234328°。
- 对应动捕局部yaw约-1.274543°、PX4 yaw约-47.109135°；PX4当时yaw_align=true、mag_hdg=true，参考来自其磁航向估计。

将绕共同向下轴的旋转 Rz(-45.834592°) 左乘原 world→labFRD：
R_world_to_px4 = Rz(delta) · R_world_to_lab。
**位置和完整姿态用同一个旋转**，不改变机体安装旋转、原点或尺度。得到矩阵：

    [[ 0.7173313877,  0.6967321438, 0],
     [ 0.6967321438, -0.7173313877, 0],
     [ 0,             0,         -1]]

仅在带明确来源的临时配置中选择 px4_heading_aligned_ned / PX4 POSE_FRAME_NED；含义是将动捕对齐到当次 PX4 的 NED 航向估计，而非宣称独立测得地理北向。绝对北向误差和室内磁干扰仍未知。不能将此快照直接作为双机共享参考，后续须建立统一标定。

原严格配置及普通 receive_ground 配置仍输出局部FRD；没有只把原坐标的frame字段改为NED。检查代码要求候选矩阵与记录旋转一致，拒绝缺少来源、伪造north_verified、只改标签未旋转的位置/姿态。候选只允许显式接收时间地面模式，真实输出还受原有地面门禁约束。

快照限制同一Jetson boot、采集后10分钟内显式启动。该有效期只是限制陈旧重用，不能证明磁参考在整个时段可靠，也不是飞行校准质量指标。未自动在线学习、跟随或重设参考轴；不会随飞机移动自动重对齐。
