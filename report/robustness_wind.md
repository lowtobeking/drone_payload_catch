# M6 干扰鲁棒性优化：侧风下的垂直交接

> 本文记录一次**给 M6 垂直堆叠投放加干扰并做鲁棒性优化**的完整探索：
> 干扰从哪来 → 为什么原来会失败 → 加了什么优化 → 优化后能扛多大干扰 → 还剩什么没解决。
>
> 复现：
> ```bash
> python3 tools/stack_run.py --scenario M6_stack_wind          # 单次（默认已含速度前馈）
> python3 tools/stack_run.py --scenario M6_stack_wind --lead 1.0
> python3 tools/stack_run.py --sweep-wind                       # 侧风扫掠（两种干扰制度）
> ```
> 相关文件：`payload_catch/stack_drop.py`（`simulate_stack` 新增 `lead / vel_ff / meas_lpf_alpha`）、
> `config/catch_scenarios.yaml`（新增 `M6_stack_wind`）。

---

## 1. 问题：M6 原来对侧风"免疫"（因为根本没建模）

原 M6 离线仿真里载荷是 `drag_mode='none'`，而风只有在有阻力时才起作用——
**所以原来的 M6 仿真对风完全无感**，SITL 里也没有侧风。

真实的垂直交接会有侧风：载荷离手后水平方向被风拖着漂移，而 B 的漏斗口径只有
`eff_r = mouth_radius − object_radius = 0.20 − 0.05 = 0.15 m`（实际有效半径约 0.14 m）。
**一点点漂移就会把载荷吹出漏斗口。**

### 1.1 干扰模型（复用了仓库已有的 `PayloadModel`）

- 载荷水平阻力 `linear, drag_k`（1/s）+ 常值风 `wind=[w,0,0]`：
  ```
  a_drag = −k·(v − w)   ⇒   v(t) = w·(1 − e^{−kt}),  x(t) = w·(t − (1−e^{−kt})/k)
  ```
- 在 0.54 s 的下落窗口里，`k=1` 时水平漂移 ≈ `0.107·w`（w=2 → 0.21 m，w=3 → 0.32 m）。
  **漂移量已远大于 `eff_r=0.15 m`**，所以风一大必失败。
- 叠加释放误差 `σ_pos=0.05 m`、相对定位噪声 `σ=0.05 m`、延迟 `0.05 s`。

---

## 2. 诊断：失败不是"位置不够"而是"追尾滞后"

把一次失败跑逐拍打印（w=2, k=1, seed=3）：

```
   t     pB_x     pP_x      dx(错位)
0.000    0.000    0.102   -0.102
0.240    0.008    0.164   -0.156
0.360    0.036    0.230   -0.194
0.540    0.131    0.364   -0.233   ← 接触时刻错位 0.23m ≫ eff_r=0.15m
```

B 一开始就滞后，且**越追越落后**。根因是控制律：

```
a_cmd = a_ref + kp·(p_ref − p_B) + kd·(v_ref − v_B),   而 v_ref,xy = 0
```

`v_ref,xy = 0` 意味着 `kd` 项是**"把 B 往零速度拉"的阻尼**，不是速度跟踪。
对一个以速度 `v_t` 移动的目标，该 PD 的稳态跟踪误差为

```
e_ss = kd·v_t / kp           （无速度前馈时的追尾滞后）
```

`kp=9, kd=6` ⇒ `e_ss ≈ 0.67·v_t`。载荷漂移末端速度越大，滞后越大——这就是失败根源。

---

## 3. 优化：速度前馈 + 预测式对正（lead pursuit）

### 3.1 速度前馈（消除追尾滞后）

把 B 的水平速度参考设为**载荷水平速度估计** `v̂`，而不是 0：

```
v_ref,xy = v̂        ⇒  稳态滞后 e_ss → 0
```

`v̂` 用有限差分 + EMA（`vel_alpha`）估计。这一项单独就把 w=2 从 **0/30 救到 28/30**（§4 表）。

### 3.2 预测式对正（lead pursuit，提前拦截）

载荷在延迟/漂移下，B 看到的是"过去的位置"。把水平目标外推到接触时刻：

```
p_ref,xy = p_meas,xy + lead · v̂ · (t_c − t)
```

`lead=0` 是追尾，`lead≥1` 是拦截。`lead=1.0` 在 w=3 把它从 5/30 提到 **25/30**。

### 3.3 测量低通（重噪声下必需）

相对定位噪声会直接驱动 B（`kp·噪声`），并让 `v̂` 的差分噪声放大（`≈σ/dt`）。
加一阶 EMA（`meas_lpf_alpha`，SITL 用 `≈0.30`）抑制。这与 SITL 里 `est_lpf_alpha` 的做法一致。

> 默认：`vel_ff=True`（严格改进，永远开）；`lead` 默认 0，推荐 1.0~1.5；`meas_lpf_alpha` 视噪声开。

## 4. 结果：侧风扫掠（k=1.0, n=30/格, eff_r=0.15m）

### 制度 A：纯风扰动（只有释放误差 0.05m，相对定位干净）

| 侧风 w (m/s) | 原始追尾 | +速度前馈 | +预测对正(lead=1) |
|---|---|---|---|
| 1.0 | 24/30 h=0.119 | 30/30 h=0.064 | **30/30 h=0.048** |
| 2.0 | **0/30** | 28/30 h=0.116 | **30/30 h=0.084** |
| 3.0 | **0/30** | 5/30 h=0.147 | **25/30 h=0.116** |
| 4.0 | 0/30 | 0/30 | **10/30 h=0.139** |
| 5.0 | 0/30 | 0/30 | 0/30 |

**侧风容忍边界（成功率 ≥50%）**：原始 ≈1 m/s → +速度前馈 ≈2.5 m/s → **+预测对正 ≈3.5 m/s**，
提升了约 **3.5 倍**。这就是"在一定干扰下也能实现"的定量证据。

### 制度 B：风 + 相对定位噪声（0.05m / 0.05s）

| 侧风 w (m/s) | 原始追尾 | +速度前馈 | +预测对正 |
|---|---|---|---|
| 1.0 | 24/30 | 27/30 | 25/30 |
| 2.0 | **0/30** | 7/30 h=0.123 | **8/30 h=0.105** |
| 3.0+ | 0/30 | 0/30 | 0/30 |

**在噪声下优化只把边界从 ~1 m/s 推到 ~1.5 m/s**——因为有限差分速度估计被噪声污染
（`v̂` 噪声 ≈ `σ√2/dt ≈ 3.5 m/s`，EMA 后仍 ~1.5 m/s），`lead` 又把这点噪声放大。
**瓶颈从"控制律"转移到了"估计器"。**

## 5. 试过但没用的优化（负结果，避免重走）

| 尝试 | 结论 |
|---|---|
| **水平积分项（泄漏积分器）** | 对恒值风扰理论最优，但 0.5s 窗口太短、相位滞后大，实测**无明显改善**（w=2 仍 7/30）。 |
| **双参数最小二乘速度估计**（`x=x0+v·τ+½a·τ²`） | 高风时略好（w=3: 0→4/30），但低风时**明显变差**（w=1: 27→2/30）——短窗加速度估计被 `τ⁴` 权重放大噪声。 |
| **单参数模型拟合**（锚定已知悬停点 `x=x_rel+½a·τ²`） | 释放位置噪声 σ=0.05 被 `2Στ²/Στ⁴ ≈ 6.7` 放大成 ~0.67 m/s² 的**虚假漂移加速度**，几乎全失败。**先验锚定反而有害**。 |
| **提高积分增益 ki / 降截止** | 同上，无改善。 |

**共同教训**：这些方法都在"用带噪测量估计加速度/速度"，而**问题本质是估计器在短窗 + 噪声下的
可观测性差**，不是控制律形式的问题。

---

## 6. 剩余瓶颈与下一步

1. **估计器是当前瓶颈**（制度 B）。正确做法是用 **卡尔曼滤波**（`payload_catch/payload_filter.py`
   已有）对载荷水平状态做**模型化**估计（已知重力、可估常值风），而不是有限差分。
   预测：KF 能把 `v̂` 噪声降一个数量级，从而让 `lead` 在噪声下也生效。
2. **`eff_r` 太小是根本余量问题**。当前 `eff_r=0.15 m`，而漂移+噪声 ~0.2-0.3 m。
   加大漏斗（depth/口径）或加**机械臂 reach**（见 `report/handoff_exploration.md` §3.2）
   可直接把容忍度翻倍——**这是性价比最高的一步**。
3. **已知风前馈**：若风可测/可估（常值），可直接把它作为 B 的参考偏移，无需在线差分。
   这是"干扰前馈"而非"干扰反馈"，对常值扰动最有效。
4. **A 端预补偿**：若风已知，A 向迎风侧悬停偏移 `½ a_wind t_c²`，让载荷正好飘到 B 头上。

## 8. 一句话结论

**侧风是"系统性可预测干扰"，用"速度前馈 + 预测式对正"即可把 M6 的侧风容忍从 ~1 m/s 提到 ~3.5 m/s
（≈3.5×）；但测量噪声会把这套优化打回 ~1.5 m/s，说明下一步该投资的是"模型化估计器（KF）
与大余量末端（大漏斗/机械臂 reach）"，而不是继续调控制律。**
