# 协调理论：三条新结果（T1 最优性 / T2 联合证书 / T3 延迟 CBF）

> 研究理论补强。把 C1–C5 从"应用"提升为"可证结果"：
> **T1** 释放策略最优性（C1）；**T2** 联合 handover 证书（C1×C5）；**T3** 延迟 CBF 鲁棒界（C5）。
> 复现：`python3 tools/coord_optimal.py`（T1）、`python3 tools/coord_cbf.py`（T3）。

## T1 释放策略的最优性（C1）

**设定.** 估计 `δ̂∈ℝ²`；真实脱靶 `m | δ̂ ~ N(δ̂, σ_m² I₂)`；捕获 `E = {‖m‖ ≤ r_eff}`。
条件捕获
```
p(δ̂) := P(E | δ̂) = 1 − Q₁( ‖δ̂‖/σ_m , r_eff/σ_m )
```
关于 `‖δ̂‖` **单调不增**（Marcum-Q 的非中心性单调）。释放策略 = 可测集 `S`（当 `δ̂∈S` 释放）。

**问题.**
```
max_S   P(δ̂ ∈ S)
s.t.    P(E | δ̂ ∈ S) ≥ 1 − ε
```

**定理 T1.** 最优释放域是**中心球** `S*(ε) = {‖δ̂‖ ≤ T(ε)}`，其中 `T(ε)` 由
`P(E | ‖δ̂‖=T) = 1−ε` 唯一确定。

**证明.** 约束等价于 `∫_S (1−p) f ≤ ε ∫_S f`。用 Neyman–Pearson/Lagrange：对乘子 `μ`，
逐点最大化被积函数 `1 − μ(1−p(δ̂)−ε)`，其正性集为 `{1−p(δ̂) ≤ c}`；因 `1−p` 关于 `‖δ̂‖` 单调不减，
该集即 `{‖δ̂‖ ≤ T}`。故最优域为球。∎

**数值验证（`coord_optimal.py`，n=8×10⁵，σ0=0.25，σ_m=0.036，r_eff=0.25，ε=0.05，条件捕获=0.95）：**

| 释放域 | 释放概率 | 条件捕获 |
|---|---|---|
| **ball {‖δ̂‖≤T}** | **0.3448** | 0.9500 |
| square {max\|x\|,\|y\|≤T} | 0.3191 | 0.9500 |
| offset-ball c=0.10 | 0.1715 | 0.9500 |

> **球域释放概率最大**（较方形 +2.6 个百分点、较偏心球 +17.3），与 T1 一致。
> ⇒ 项目现行的"`‖δ̂‖+kσ ≤ R`"**恰好是最优形式**（阈值化范数），只是 `k` 未标定（C1 v1/v2）。

## T2 联合 handover 证书（C1 × C5）

**设定.** 相对状态 `r=p_A−p_B`；B 执行速度级 CBF（C5）；释放门 `G = {‖δ̂‖ ≤ T(ε)}`（T1）。

**定理 T2.** 在 CBF 可行（`c ≥ −‖r‖v_max`）前提下：
1. **不变性**：`‖r(0)‖ ≥ d_safe ⇒ ‖r(t)‖ ≥ d_safe·e^{−αt/2} > 0`（永不碰撞，交接前后均成立）；
2. **可达性（门）**：若在 `τ` 释放且 `δ̂(τ) ∈ G`，则 `P(capture | release) ≥ 1−ε`；
3. **相容性**：若把 CBF 的 keep-out 设计为**仅约束竖直分离**（`‖r_z‖ ≥ d_safe`），
   而门 `G` 只约束**水平残差**，则两者可同时满足 ⇒ **存在同时安全且可捕获的策略**。

**证明.** (1) 速度级指数 CBF 的标准结论（`ḣ+αh≥0 ⇒ h(t)≥h(0)e^{−αt}`）。(2) T1 的直接推论。
(3) 由垂直/水平约束正交，构造"B 保持低于 A 达 `d_safe`、同时水平对正到 `G`"的轨迹即可。∎

> **意义**：把 C1（可达）与 C5（不变）从"并列"合成**一个交接证书**；并指出**夹角条件**
> （垂直 keep-out 与水平门正交）是二者相容的关键——这也解释了项目 `min_ab_gap` 设计为何有效。

## T3 延迟 CBF 的鲁棒界（C5）

**设定.** B 只能获得**延迟** `d` 的 A 相对状态 `r(t−d)`（通信延迟）。相对位移满足
```
‖r(t) − r(t−d)‖ ≤ ρ := (v_A^max + v_B^max)·d
```

**定理 T3（鲁棒化）.** 若 B 在**延迟状态**上对**收紧屏障**
```
h_d(r) = ‖r‖² − (d_safe + ρ)²
```
执行 CBF，则真实安全 `h(r(t)) = ‖r(t)‖² − d_safe² ≥ 0` 对所有 `t` 成立。

**证明.** CBF 保证 `‖r(t')‖ ≥ d_safe + ρ` ∀`t'`（在延迟状态上）。取 `t'=t−d`：
`‖r(t−d)‖ ≥ d_safe+ρ`，配合 `‖r(t)−r(t−d)‖≤ρ` ⇒ `‖r(t)‖ ≥ d_safe`。∎

**数值验证（`coord_cbf.py`，A/B 各以 0.8 m/s 相向，d_safe=0.8）：**

| delay (s) | naive 最小间距 | 安全? | robust 最小间距 | 安全? |
|---|---|---|---|---|
| 0.00 | 0.873 | ✅ | 0.873 | ✅ |
| 0.05 | 0.858 | ✅ | 0.920 | ✅ |
| 0.10 | 0.813 | ✅ | 0.939 | ✅ |
| **0.20** | **0.739** | **❌** | 0.996 | ✅ |
| **0.30** | **0.665** | **❌** | 1.060 | ✅ |

> **发现**：用**延迟状态**的朴素 CBF 在 `d≥0.2s` **突破安全界**；用 `ρ=(v_A+v_B)d` 收紧后**全程安全**。
> ⇒ 交接安全证书必须显式包含**通信延迟的鲁棒余量**（与 C2 的时序界呼应）。

## 小结：理论把"应用"提升为"结果"

| | 结果 | 类型 | 验证 |
|---|---|---|---|
| **T1** | 释放域最优 = 中心球 | 定理（NP/单调似然比） | `coord_optimal.py`（球域释放概率最大） |
| **T2** | 不变性 + 可达性 + 相容性的**联合证书** | 定理（组合） | 交接轨迹（C5 报告） |
| **T3** | 延迟下 `ρ=(v_A+v_B)d` 收紧保证安全 | 定理（鲁棒 CBF） | `coord_cbf.py`（naive 违反/robust 安全） |

**这三条 + C1–C5 = 一个带保证的协调框架**：何时释放（T1）、如何保证时序（C2）、共享什么（C3）、
如何联合机动（C4）、如何保安全（T2/T3）。

## 局限（诚实）

- T1 假设 `m|δ̂` 为**无偏高斯**；偏差/相关需 C1-v2 的扩展（已给保守处理）。
- T3 的 `ρ` 用**最坏速度界**，保守；可用概率界 `k·σ_d` 收紧。
- T2 的相容性给了**充分条件**（正交约束），非充要。
- 均为**离线解析 + 数值**，尚未全部接入 SITL / 真机。
