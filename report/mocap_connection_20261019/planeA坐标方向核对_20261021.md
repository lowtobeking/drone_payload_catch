# planeA 动捕方向地面核对

本轮均由操作员手动移动未解锁飞机；仅原生VRPN采集，没有发布外部里程计、控制指令或改参数。

- 向上抬高：原始Z从约0.291增加至1.184，支持+Z朝上。实际移动距离未独立测量，不据此验收尺度。
- 首次机头前移：delta约[-0.04493,+0.60692,+0.00089]米，当前前方约+Y。
- 同朝向右移：delta约[+1.17732,+0.10117,-0.00082]米，右侧约+X。
- 第一次所谓逆时针被用户纠正为侧立机身，不用于航向标定。原记录planeA_ccw_result_20261021.json保留。
- 恢复水平后另记基准，再水平机头左转：四元数相对旋转约85.1度，主要绕原始世界+Z，符合逆时针。
- 换朝向后再次前移：delta约[-0.980063, -0.016354, 0.002128]米，主要为-X，符合预期。动捕水平位移约0.980米。

在标准主动body-to-world/xyzw解释下，两次前移均提示机头相对刚体+X约-90度，不能把原始刚体四元数直接当PX4 FRD机体姿态。手动前移及机头保持有数度误差，固定偏移仍需按刚体轴显示或重复测量核实；不将这组数据作为精密安装角标定。桥接需要世界变换和机体安装变换同时正确，保持A/B共享场地原点，不各自自动归零。

VRPN约120Hz；部分采集包含1次非递增时间戳，后续桥接应拒绝重复/倒退帧并跟踪源时间、延迟和失联，不能用接收频率代替新鲜度验证。
