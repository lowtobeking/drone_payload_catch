# C1：释放决策的概率模型与捕获概率证书（v2：精确 Rice 证书）

> 研究 W2 / 论文核心理论贡献。把"何时释放"从**启发式余量闸**升级为**可证明的证书**，
> 并用**精确的非中心卡方（Rice/Marcum-Q）**给出紧的阈值。
> 复现：`python3 tools/coord_prob.py --n 300000`（离线、秒级、大 N，seed=0）。

---

## 1. 模型与假设

| 量 | 含义 | 分布 |
|---|---|---|
| `δ_true` | 释放时"B 漏斗中心 − 载荷落点"的真实水平残差 | `N(0, σ0² I₂)` |
| `e` | 决策者对它的**估计误差**（相对定位 + 通信） | `N(b·x̂, σ_e² I₂)` |
| `δ̂ = δ_true + e` | 决策所用估计 | — |
| `w` | 释放后 B 的**跟踪残差** | `N(0, σ_track² I₂)` |
| `m = δ_true + w` | **真实水平脱靶** | `N(μ, σ_m² I₂)`，`μ=δ̂`，`σ_m²=σ_e²+σ_track²` |

- **捕获**：`E = {‖m‖ ≤ r_eff}`（速度条件由漏斗物理 `v_retain` 保证）。
- **策略**：`‖δ̂‖ ≤ T` 时释放（`T` 由证书给），否则继续等/中止。
- **谁能减小 σ_e**：`direct`（B 用带噪相对定位）σ_e 大；`authority`（A 用精确自身 + B 上报）σ_e 小。
- **延迟**：A 以 `v_A` 运动时引入偏置 `b = v_A·d`。

## 2. 证书（精确）

**定理（Rice / 非中心卡方）.** 设 `m ~ N(μ, σ_m² I₂)`，则 `‖m/σ_m‖² ~ ncx2(df=2, nc=(‖μ‖/σ_m)²)`，故
```
P(‖m‖ ≤ R) = F_{ncx2}( (R/σ_m)² ; df=2, nc=(‖μ‖/σ_m)² )
```
`‖m‖` 服从 **Rice 分布**（等价 Marcum-Q：`P(‖m‖≤R)=1−Q₁(‖μ‖/σ_m, R/σ_m)`）。

**证书.** 释放时令 `μ=δ̂`。因 `P(capture|δ̂)` 关于 `‖δ̂‖` 单调递减，取
```
T(ε) = argmax_T { P(‖m‖ ≤ r_eff − margin | μ=T) ≥ 1−ε }
```
则 `‖δ̂‖ ≤ T(ε) ⇒ P(capture) ≥ 1−ε`。（`μ=0` 时退化为 Rayleigh 精确式 `T=σ_m√(2 ln(1/ε))`。）

**保守闭式（Chernoff 界）**：`T = R − √(2 ln(1/ε))·σ_m`（更松）。
**旧启发式**：`T = R − 1·σ_m`（项目 `release_sigma_k=1`）。
> `k=1 ⇒ ε_eff = e^{−1/2} ≈ 0.61`——即旧闸**没有可陈述的保证**。

## 4. 策略对比（eff_r=0.25, ε=0.05, margin=0.05, n=3×10⁵）

| 方法 | 策略 | σ_e | T | 释放率 | 中止率 | 成功率 | 条件捕获 |
|---|---|---|---|---|---|---|---|
| **exact** | direct | 0.06 | 0.080 | 0.273 | 0.727 | **0.273** | 1.000 |
| **exact** | authority | 0.02 | 0.151 | 0.814 | 0.186 | **0.814** | 1.000 |
| chernoff | direct | 0.06 | 0.045 | 0.097 | 0.903 | 0.097 | 1.000 |
| chernoff | authority | 0.02 | 0.131 | 0.715 | 0.285 | 0.715 | 1.000 |
| heuristic | direct | 0.06 | 0.137 | 0.609 | 0.391 | 0.608 | 1.000 |
| heuristic | authority | 0.02 | 0.172 | 0.886 | 0.114 | 0.886 | 1.000 |

**发现**：
1. **精确证书把 direct 的成功率从 0.097→0.273（×2.8）、authority 从 0.715→0.814**，保证不变——保守界代价很大。
2. **authority 大幅优于 direct**（exact：0.814 vs 0.273）——σ_e 更小 ⇒ T 更大 ⇒ 更早释放、更少中止。
3. 启发式成功率更高（0.886）但**没有保证**；它是在"赌"。

## 8. SITL 接入与验证（证书闸）

把证书接入 `a_node`（`release_gate_mode=certificate`），并把核心数学抽成无 ROS 依赖的
`payload_catch/coord_cert.py`（工具与节点共用）。

**信息改动**：B 的 `/drone_b/ready` 扩为 `[ready, rel_xy, spd_xy, stamp, sigma_abs, sigma_rel]`——
`sigma_rel` 是**纯相对定位残差**（不含 EKF 绝对 σ），供证书闸用；`sigma_abs` 保留给 keep-out/启发式。

**新增参数**：`release_gate_mode`(heuristic|certificate)、`cert_eps`、`cert_sigma_track`。

**单元验证**：B 上报 6 元 `[.., 0.153, 0.03]`；A 证书闸 `σ_m=0.036, T=0.137`，
`rel=0.02<T` 通过、`rel=0.20>T` 拦截。

**SITL**（`COORD=handshake FUNNEL_MOUTH=0.30 release_gate_mode:=certificate`）：
```
A: 就绪门限通过 → 提交窗口 → 释放权威发布 release@... (lead=0.2, σ=0.026)
*** STACK CAPTURED horiz=0.058m ***   无 failsafe
```
> **关键对比**：证书闸用的是**相对 σ=0.026**；启发式闸（同场景）用的是**绝对 σ=0.150**（被 A 的 eph 主导）。
> 这正是 C1 要修正的：**用绝对 σ 会让标准漏斗无法认证，用相对 σ 则可认证且可释放**。

## 10. 结论（可写进论文）

1. **精确证书**：`P(capture) = F_{ncx2}((R/σ_m)²;2,(μ/σ_m)²)`；阈值 `T(ε)` 使 `P(capture)≥1−ε`；
   无偏时 Rayleigh 精确，`k=√(2 ln(1/ε))`。
2. **比保守界强得多**：Chernoff 界把 direct 成功率压到 0.097，精确解恢复到 0.273。
3. **校准/可行性**：现用 `k=1` 无保证；标准漏斗在 `rel_σ≥0.10` 无法保证 95%，大漏斗可以。
4. **协调收益**：`authority`（精确自身状态）在两个界下都显著优于 `direct`。
5. **延迟**：运动交付被 `b=v_A·d` 直接消耗余量（v1 扫描：v_A=1,d=0.2 时成功率 0.575→0.088）。
