# 空心导向锥杯：建模 + SITL + 物理测试（含一个负结果）

> 承接 `report/robust_geometry_and_retention.md` §B / `tools/funnel_model.py`：
> 末端机构是"落点半径/保持"的关键杠杆。本文把**实心平顶盘**升级为**空心导向锥杯**并实测其价值。
>
> 复现：
> ```bash
> python3 tools/gen_funnel_cup.py                 # 生成杯模型
> bash tools/funnel_drop_test.sh                   # 独立物理测试（可 TILT=... OFFX=... 覆盖）
> FUNNEL_TYPE=cup bash run_m6_sitl.sh 70           # SITL（空心杯）

---

## 0. 结论速览

1. **空心锥杯已建成并在 SITL 跑通**：`FUNNEL_TYPE=cup` → `STACK CAPTURED`，载荷被"导向"到杯内并随 B 飞行。
2. **但要诚实记一个负结果**：独立物理测试显示，**敞口杯在平台倾斜时反而不如高摩擦平顶盘**——
   倾斜 >25° 时杯内载荷会从低侧滚出，而平顶盘靠摩擦（μ=1）能撑到 ~45°。
3. 杯的**真正价值是"导向 + 侧向速度兜接"**（把偏心/带横向速度的载荷导到中心，而不是滑出），
   这在解析模型里成立（水平容差 2.2→3.1 m/s），但**幅度有限**，且 primitive 壁在偏心撞击下数值较脆。
4. **结论**：要真正解决"姿态/携带"鲁棒性，敞口杯不够，应上**主动保持（锁扣/磁吸）**或
   **带内唇/更深的杯**（或 mesh 漏斗）。这与 `tools/funnel_model.py` 的结论一致（主动保持 `v_retain` 8 m/s）。

## 3. 独立物理测试：倾斜平台上杯 vs 平盘

落点偏移 0.15m，投到倾斜的空心杯 / 实心平盘上，读 6s 后位移：

| 平台倾角 | 空心杯（末态 x,z） | 平顶盘（末态 x,z） |
|---|---|---|
| 0° | −0.156, 0.011 → **保持** | +0.150, 0.040 → **保持** |
| 25° | −3.67, −49.8 → **滑出/掉落** | +0.150, 0.039 → **保持** |
| 45° | −6.79, −53.4 → **滑出/掉落** | −8.62, −60.5 → **滑出/掉落** |

**读数**：**敞口杯在 25° 就丢载荷，平顶盘能撑到 ~45°**（摩擦 μ=1，tan45°=1）。
原因是敞口杯的**低侧杯口会低于杯底**，载荷沿内壁滚到低侧就翻出去；平顶盘没有这个"滚出"通道。

**保持条件（解析）**：载荷静置于杯底、要越过低侧杯口翻出需
`tanθ < DEPTH/R_mouth = 0.14/0.30 ≈ 0.47 → θ < 25°`。
而平顶盘的摩擦上限是 `θ < atan(μ) = 45°`。**所以在这个几何下，敞口杯的倾角鲁棒性不如高摩擦平盘。**

---

## 4. 与解析模型对照

`tools/funnel_model.py`（同一口半径）给出：
- `eff_r` 三种机构相同（口半径决定）；
- 空心锥把**水平速度容差**从平盘摩擦的 2.21 m/s 提到 ~3.13 m/s（内壁兜住）；
- **主动保持（锁扣/磁吸）**把 `v_retain` 提到 8 m/s、`tilt_max` 近 180°。

即：**杯的价值在"侧向兜接/导向"，不在"倾角保持"；倾角/携带要靠主动保持。**

---

## 5. 结论与下一步

**结论（含负结果）**
1. 空心锥杯已实现并能 SITL 捕获；`FUNNEL_TYPE=cup` 可切换。
2. **但敞口杯在倾斜平台上不如高摩擦平顶盘**（25° vs 45°）——"导向"换来的代价是"低侧开口可滚出"。
3. 因此**不应把敞口杯当作姿态/携带鲁棒性的解决方案**；它的合理用途是**引导偏心/带横向速度的落点**。
4. primitive 壁在偏心撞击下数值较脆（载荷会横穿/弹跳）；要做真漏斗建议 mesh 或加内唇。

**下一步（按价值）**
1. **主动保持机构**（低回弹锁扣 / 磁吸 / 夹爪）：真正把"砸住"升级为"导向—夹持—带走"，
   并解决 `v_retain`/倾角（解析：`v_retain` 4→8 m/s，tilt→~180°）。
2. **带内唇/更深的杯**（`tanθ < DEPTH/R` 要 > μ），或 mesh 漏斗 + 内唇。
3. 把"倾角/携带"作为**独立判据**加入离线模型（目前只判 `eff_r` 与 `rel_v`）。
