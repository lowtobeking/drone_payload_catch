# 交接场景深度探索：公式推导与边界分析

> 本文是对 `drone_payload_catch` 的**方向性扩展探索**，回答四个问题：
> **静态交接、动态交接、机械臂丢接、增加速度的交接**各自的物理边界在哪里、公式是什么、
> 现有实现还缺什么。
>
> 所有数值均可由 `python3 tools/handoff_explore.py` 复现（纯 Python，无 ROS）。
> 结论与 `MEMORY.md`/`README.md` 的既有结果衔接，但把"经验结论"升级为"闭式公式 + 边界"。

---

## 0. 符号与坐标

- 世界系 **NED**（x=北，y=东，z=下）。重力 `g = [0,0,+9.81]`。
- 推导中竖直方向改用**高度 h = −z**（向上为正），更直观；必要时注明 NED。
- 载荷：质量 m，无阻力抛体（M6 场景纯垂直）。
- 交接双方：
  - **A**（投送方）：位置 `p_A`，速度 `v_A`（悬停时 `v_A=0`；平飞时水平速度 `u`）。
  - **B**（接收方）：位置 `p_B`，速度 `v_B`，加速度限幅 `a_max`，速度限幅 `v_max`。
  - **臂**（可选，装在 A 或 B 上）：抛掷速度 `v_throw`、reach `r_arm`、端部吸收速度 `v_arm`。
- 漏斗捕获判据（M6 已确立，本文沿用）：
  ```
  位置：载荷落到漏斗口平面时，水平偏差 < mouth_radius − object_radius
  速度：接触相对速度 ≤ v_retain = √(2·g·depth) / e        (e = 恢复系数)
  ```

**核心问题**：一次交接能不能成，取决于一条**速度/位置预算式**：

```
接触相对速度 v_rel  =  垂直分量（重力积累 − B 下潜抵消）
                     +  水平分量（A 速度继承 + 臂抛掷残余）
约束：v_rel ≤ v_retain(漏斗) 或 v_retain + v_arm(臂吸收)；
     水平偏差 ≤ 口内有效半径(漏斗) 或 + r_arm(臂 reach)。
```

下面逐项把这个预算式拆开。

## 1. 静态交接（A 悬停、B 正下方下潜接）

### 1.1 接触时间与相对速度

A 在高度 `h_A` 悬停，B 在 `h_B` 待命，`gap = h_A − h_B`。载荷自由落体，B 以恒定加速度
`a_dive`（向下，`0 ≤ a_dive < g`）下潜。用高度坐标：

```
载荷：y_p(τ) = h_A − ½gτ² ,   v_p(τ) = −gτ
B   ：y_B(τ) = h_B − ½·a_dive·τ² ,  v_B(τ) = −a_dive·τ
```

接触条件 `y_p = y_B`：

```
h_A − ½gτ² = h_B − ½ a_dive τ²
⇒ ½(g − a_dive) τ² = gap
⇒ τ_c = √( 2·gap / (g − a_dive) )
```

接触相对速度（向上为正的速率）：

```
v_rel = g·τ_c − a_dive·τ_c = (g − a_dive)·τ_c = √( 2·(g − a_dive)·gap )
```

这就是 M6 的**物理下界**：`a_dive` 越大 `v_rel` 越小，但 `a_dive` 不能 ≥ g（水平悬停、漏斗朝上时
B 的向下加速度上限就是自由落体 g）。

### 1.2 高度预算：下潜越猛，吃掉的净空越多

B 下潜距离与刹停距离：

```
dive  = ½ a_dive·τ_c² = gap · a_dive/(g − a_dive)
v_B   = a_dive·τ_c
brake = v_B² / (2·a_brake) = gap · a_dive² / ((g − a_dive)·a_brake)
```

令无量纲 `α = a_dive/g`、`β = a_brake/g`，则总降高：

```
dive + brake = gap · α/(1−α) · (1 + α/β)      ← 闭式高度代价
```

即 **v_rel 降下来是有代价的**：`v_rel ∝ √(1−α)`，但高度代价 `∝ α/(1−α)(1+α/β)`，α→1 时高度代价
发散（无限降高才能把相对速度压到 0）。

### 1.3 给定净空预算的最大 a_dive 与 v_rel 下界

设 B 可用的净空预算 `Δh = h_B − h_min`（h_min 为最低允许高度，含地面余量）。可行要求：

```
Δh ≥ gap · α/(1−α) · (1 + α/β)
```

解这个关于 α 的二次方程（数值结果见 §6 表），得 `α_max`、`a_dive,max`，进而

```
v_rel,min = √( 2·g·gap·(1 − α_max) )     ← 该 gap/预算下的最小可达成相对速度
```

**结论**：静态交接的垂直速度下界由 `(gap, 净空预算, a_brake)` 三者共同决定；要把 `v_rel` 压到
`v_retain` 以内，要么加大 gap（给下潜跑道，但同时拉高 `√gap` 基数），要么抬高 B 待命高度（加预算），
要么加大 `a_brake`。

## 2. 动态交接（A 平飞抛投）

### 2.1 继承速度与终端速度

A 以水平速度 `u` 平飞，在高度 `h_A`、释放点 `p_r` 抛投。载荷继承 A 的速度：

```
p_p(τ) = p_r + [u,0,0]·τ + ½g·τ²      （g 沿 NED +z）
v_p(τ) = [u, 0, g·τ]
```

若在高度 `h_c` 捕获，下落 `Δh = h_A − h_c`，历时与终端速率：

```
τ_c = √(2·Δh / g)
|v_p| = √( u² + 2g·Δh )
```

**关键点**：水平分量 `u` 全程不变（无阻力）。所以：

- 载荷终端速率 = `√(u² + 2gΔh)`，**u 越大，B 要匹配的终端速度越大**；
- B 若采用"编队同速"策略，必须能飞到 `|v| ≥ u` 并在会合点匹配 `[u,0,gτ_c]`——受 `v_max` 约束。

### 2.2 反向抛投：把动态交接退化为静态垂直交接

若 A 上的**机械臂把载荷向 A 运动反方向掷出** `v_throw,xy = −u`，则载荷水平速度归零：

```
v_r = [u,0,0] + [−u,0,w_z] = [0,0,w_z]
```

载荷从释放点 `p_r` **纯垂直下落**，终端速率只剩 `√(2gΔh)`（数值见 §6：u=5 m/s 时从 8.61 m/s
降到 7.00 m/s，且不再要求 B 平飞匹配 u）。

**这是机械臂的第一个决定性收益**：它把"B 必须追上 A 的水平速度"这个约束，转移为"臂必须能掷出
−u"——**上限由臂的抛掷速度决定，而非 B 的飞行包线**。B 只需飞到（固定的）释放点 `p_r` 做 M6 式下潜接。

### 2.3 软终端速度的闭式解（衔接现有实现）

当"终端速度精确匹配"不可行（如 `|v_p| > v_max`）时，`rendezvous.py` 退化为软终端速度
（单轴、两端位置硬、终端速度软）：

```
min  ∫ a² dt  +  w·(v(T) − v_ref)²   s.t. x(0)=x0, v(0)=v0, x(T)=x1
```

其解为三次多项式，系数（已在 `min_energy_cubic_soft` 中实现，本文核对）：

```
D = x1 − x0 − v0·T
q = −( 2D/T² + w·(v0 + 2D/T − v_ref) ) / ( T·(4 + w·T) )
c = ( x0,  v0,  D/T² − qT,  q )
```

- `w→∞` 退化为精确匹配（自然边界 `v(T)=v_ref`）；
- `w→0` 退化为自由终端速度（自然边界 `a(T)=0`，`v(T)=3D/(2T)`）。

> 这是"速度匹配软约束"的精确形式，避免在速度超限时硬匹配失败。

## 3. 机械臂丢接（throw & catch）

### 3.1 上抛 + 顶点接：一个重要的负结果

自然的想法：A 把载荷**向上抛**，让它在最高点速度为零，B 在顶点"轻拿轻放"。推导：

```
上抛速度 w（向上）→ 顶点高度 h_apex = h_A + w²/(2g)，到达历时 τ = w/g
B 需在 τ 内从 h_B 静止爬到 h_apex 并静止（才能零相对速度接住）
位移 D = gap + w²/(2g) ，  历时 T = w/g
```

静止→静止的最小峰值加速度是 bang-bang 梯形剖面：

```
a_min = 4D / T² = 4·(gap + w²/2g)·g²/w² = 4g²·gap/w² + 2g
```

- `w→∞`：`a_min → 2g ≈ 19.62 m/s²`（**下界**）；
- 任何有限 w 的 `a_min > 2g`（见 §6 表：w=1 m/s 时已需 ~405 m/s²，因为 τ 只有 0.1 s）。

**结论（负结果）**：四旋翼 `a_max ≈ 6 m/s² ≪ 2g`，**纯垂直上抛 + 顶点零速接在旋翼平台上不可行**。
上抛的正确用法是**加长飞行时间**（给 B 争取到位时间），而不是追求顶点零速。min-energy 三次的
峰值是 `6D/T²`，比 bang-bang 还高 50%，结论不变。

### 3.2 臂的 reach：把"点匹配"放宽成"区域匹配"

当前 M6 的水平判据是 `eff_r = mouth_radius − object_radius = 0.20 − 0.05 = 0.15 m`，实测捕获
水平偏差 0.108~0.128 m，**余量只有 0.01~0.03 m**。加一个 reach `r_arm` 的臂：

```
有效捕获半径 = eff_r + r_arm
```

`r_arm=0.15 m` 即可让有效半径翻倍到 0.30 m，把最危险的"贴着漏斗边缘"变成"有近半口径余量"。

### 3.3 臂的吸收：把"速度匹配"放宽成"速度吸收"

B 身上的臂可以**顺着载荷下落方向**以 `v_arm` 运动，等效于把漏斗的保持速度上限抬高：

```
有效保持速度 = v_retain + v_arm
```

`v_arm=2 m/s` 时，`4.04 + 2 = 6.04 m/s`，比当前标称 `v_rel=3.69 m/s` 的余量从 8.7% 拉到 60%+。
臂还可以加机械闭合（夹爪/磁吸），彻底绕过 `v_retain` 的恢复系数限制。

### 3.4 小结：臂的作用矩阵

| 臂装在哪 / 功能 | 放松的约束 | 收益 |
|---|---|---|
| A 上：反向抛投 `−u` | B 的 `v_max`（水平匹配） | 动态→静态，上限=臂抛掷速度 |
| A 上：上抛 w | B 的到位时间 | 加长飞行时间（但顶点接不可行） |
| B 上：reach `r_arm` | 位置判据 | 捕获半径翻倍，余量倍增 |
| B 上：吸收 `v_arm` | 速度判据 | 有效 `v_retain` 提升 |
| B 上：机械闭合 | 恢复系数限制 | 接住→锁定→带走 |

## 4. 增加速度的交接（把边界往上推）

### 4.1 速度预算分解

一次交接的相对速度可分解为三个可独立优化的项：

```
v_rel²  ≈  v_rel,vert² + v_rel,horiz²
v_rel,vert = √(2(g − a_dive)·gap)          ← 重力积累 − B 下潜
v_rel,horiz = |v_A,xy + v_throw,xy|          ← 继承速度 + 臂抛掷残余
```

各分量的**上限/下限**：

- `v_rel,vert` 下界 = `√(2(g − a_dive,max)·gap)`，其中 `a_dive,max` 由 §1.3 的净空预算解出；
- `v_rel,horiz` 可由反向抛投**清零**（上限 = 臂抛掷速度）；
- 两者之和 ≤ 有效保持速度 `v_retain (+ v_arm)`。

### 4.2 垂直方向的边界表（数值）

`h_B=3.5 m, 净空预算 3.2 m, a_brake=6` 时（见 §6）：

| gap | a_dive,max | v_rel,min | 漏斗0.3/0.6 | 漏斗0.5/0.6 | 漏斗0.5/0.4 |
|---|---|---|---|---|---|
| 0.5 | 7.29 | 1.59 | 4.04 ✓ | 5.22 ✓ | 7.83 ✓ |
| 1.0 | 6.03 | 2.75 | 4.04 ✓ | 5.22 ✓ | 7.83 ✓ |
| 1.5 | 5.23 | 3.71 | 4.04 ✓ | 5.22 ✓ | 7.83 ✓ |
| 2.0 | 4.65 | 4.54 | 4.04 ✗ | 5.22 ✓ | 7.83 ✓ |

**含义**：gap 增大时 `v_rel,min` 也增大（`√gap` 基数压过可加大 a_dive 的收益），所以**不能靠无限
加大 gap 来提高可接速度**；真正的杠杆是**加深漏斗 / 降恢复系数 / 加臂吸收**（右三列的横向提升）。

### 4.3 提高可接速度的三个杠杆（按性价比）

1. **漏斗参数**（零飞行成本，立竿见影）：
   `v_retain = √(2g·depth)/e`。depth 0.3→0.5 m（e 不变）⇒ 4.04→5.22 m/s；
   e 0.6→0.4 ⇒ 6.07 m/s；两者同改 ⇒ 7.83 m/s。
2. **B 的净空预算**：抬高 B 待命高度 → `a_dive,max` 增大 → `v_rel,min` 下降。受任务几何限制。
3. **臂吸收 `v_arm`**：线性叠加到 `v_retain`，且可加机械闭合彻底绕过恢复系数。**最通用**。

### 4.4 水平方向：臂抛掷是"增加速度交接"的解耦器

"增加速度交接"通常意味着 A 飞得更快（u 更大）。此时：

- **编队策略**：B 必须平飞匹配 u，u 直接受 `v_max`（5 m/s）约束，且 B 高速平飞 + 末端俯冲
  会把飞控推向 failsafe（M5 已证 `v_p≈4.9 m/s` 触发 B failsafe）。
- **反向抛投策略**：载荷水平速度归零，B 保持低速/悬停接即可，u 的上限转移到**臂的抛掷速度**。

因此，"增加速度交接"的合理路线是：**用臂消掉 A 的水平速度，用深漏斗/臂吸收吃掉垂直速度**，
把 B 的飞行包线从"必须匹配 A"中解放出来。

1. **把 §4.3 的漏斗参数做成可扫描**：`depth` / `restitution` 已在 yaml 里，补一个
   `stack_run.py --sweep-funnel` 即可量化离线收益（低风险、纯参数）。

   M2 平飞工况退化成 M6 垂直工况，验证 `v_rel` 下降与成功率提升。
3. **臂 reach 的离线模型**：把捕获判据的 `eff_r` 扩为 `eff_r + r_arm`，量化"余量 0.01~0.03 m"
   对 `r_arm` 的敏感性（预期大幅改善，因为这是当前最紧的约束之一）。
4. **臂吸收的离线模型**：判据里 `v_retain → v_retain + v_arm`，看能否把 M5 的 ~4.9 m/s 边界
   往上推。
5. **SITL**：先做最简单的"加深漏斗/降 e"（改 `x500_funnel` 模型），再考虑真机械臂。

> 关键判断：**先别急着在 SITL 里做真机械臂**。离线层先用 `v_throw / r_arm / v_arm` 三个参数
> 把收益边界量出来（它们都是判据/初速的一行改动），确认哪一项价值最大，再决定 SITL/真机的投入。

## 7. 结论（一句话版）

1. **静态交接**有可解析的垂直速度下界 `√(2(g−a_dive)gap)` 与高度代价
   `gap·α/(1−α)(1+α/β)`，加大 a_dive 压速度的同时要付净空，存在预算反解的 `a_dive,max`。
2. **动态交接**的终端速率 `√(u²+2gΔh)` 里，水平分量 u 是 B 的飞行包线负担；**反向抛投 −u
   可把它清零**，把动态交接退化成静态垂直交接。
3. **机械臂**：上抛+顶点接是**负结果**（B 爬升峰值加速度 ≥2g≈19.6 m/s²，旋翼做不到）；
   真正值钱的是**反向抛投消速、reach 扩捕获半径、臂吸收提 v_retain**。
4. **增加速度**的杠杆排序：**深漏斗/低恢复系数（零飞行成本）> 臂吸收 > 抬 B 待命高度**；
   gap 增大反而抬高 `v_rel` 基数，不能滥用。
