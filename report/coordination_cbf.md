# C5：交接过程的安全证书（handover-CBF）

> 研究 W4 / 论文贡献 C5。为"接近→对正→释放→下潜"整个过程提供**安全证书**：
> ① 防碰不变集（相对一阶**速度级 CBF**）；② 交接门（复用 C1 捕获证书）。
> 复现：`python3 tools/coord_cbf.py --n 50000`。

---

## 1. 为什么用速度级（相对一阶）CBF

项目执行层是 **PX4 Offboard 速度控制**，故 CBF 取相对一阶：
```
h(r) = ‖r‖² − d_safe²,     r = p_A − p_B
ḣ = 2 r·(v_A − v_B)
条件： ḣ + α h ≥ 0   ⇔   r·v_B ≤ r·v_A + (α/2)·h        （B 的约束）
⇒ 指数 CBF：  h(t) ≥ h(0)·e^{−α t} > 0   ⇒  ‖r(t)‖ ≥ d_safe·e^{−α t/2}（永不碰撞）
```

## 2. 安全滤波（闭式投影）

B 取标称速度 `v_B^nom`，投影到可行集 `{r·v_B ≤ c} ∩ {‖v_B‖ ≤ v_max}`，`c = r·v_A + (α/2)h`：
- 若 `r·v_B^nom ≤ c` 且 `‖·‖≤v_max`：不变；
- 否则投影到平面 `r·v = c`，再限制在球内（**闭式**，见 `tools/coord_cbf.py:project_cbf`）。

A 用对称约束（`r→−r`；`c = −r·v_B + (α/2)h`）。**双方各自局部执行 = 去中心化。**

## 3. 可行性条件（命题）

滤波可行 ⇔ `c ≥ −‖r‖·v_max`，即
```
v_max ≥ ‖v_A‖ − (α/2)·h/‖r‖
```
**含义**：本机的速度预算必须涵盖**相对接近速度**；否则任何滤波都无法保证（控制权限不足）。

## 4. 结果（n=5×10⁴，d_safe=0.8，v_max=5，α=1）

| | 满足 `ḣ+αh≥0` 比例 | 最坏 `ḣ+αh` |
|---|---|---|
| 未滤波 | **56.8%** | — |
| **CBF 滤波** | **100.0%** | **−0.0000** |

（仅统计**可行样本**，占比 91.7%。）

> **发现**：在可行域内，速度级 CBF 把安全条件满足率从 56.8% 提到 **100%**（数值上 0 违反）；
> 不可行的 8.3% 由 `v_max` 不足导致（必要时需降低接近速度或提高 `v_max`）。

## 5. 交接轨迹（含 C1 交接门）

A 悬停 → B 上近（对正残差 `0.20·e^{−t/0.5}` 收敛）→ **C1 证书通过（`rel_xy ≤ T`）后释放** → B 下潜；
双方均执行 CBF。

| α | 最小间距 | ≥ d_safe | 释放时刻 | C1 阈值 T |
|---|---|---|---|---|
| 1.0 | 0.964 | ✅ | 0.20s | 0.137 |
| 2.0 | 0.933 | ✅ | 0.20s | 0.137 |

> 全程最小间距 ≥ `d_safe=0.8`；释放仅在证书达标后发生 ⇒ **"永不碰撞 + 释放可达"同时成立**。

## 6. 与现有代码的关系

| | 现有（启发式） | C5（形式化） |
|---|---|---|
| 防碰 | `px4_iface._keepout_velocity`（排斥 + 去内向） | 相对一阶 **CBF + 闭式投影**（不变集保证） |
| 监督 | 分级安全状态机 `_safety_update`（OK/HOLD/PULLBACK/LAND/KILL） | 保留（**离散监督**层） |
| 释放门 | `a_node` 余量闸 / 证书闸（C1） | **handover 门 = C1 证书** |

C5 可作为 `_keepout_velocity` 的**形式化升级**：把"排斥+去内向"换成 CBF 约束，
获得 `‖r(t)‖≥d_safe e^{−αt/2}` 的**可证保证**；安全状态机仍是上层的离散兜底。

## 7. 结论（可写进论文）

1. **速度级 CBF**（与项目接口一致）给出防碰**不变集**，可行域内 100% 保证。
2. **可行性条件** `v_max ≥ ‖v_A‖ − (α/2)h/‖r‖`——速度预算 vs 相对接近速度。
3. **交接门复用 C1 证书**：释放可达 + 不碰撞 = 交接安全证书。
4. 与 C1/C2/C3/C4 共同构成协调的**理论五件套**。
