# C3：state vs intent —— 信息共享对协调延迟的容忍

> 研究 W3 / 论文贡献 C3。问题：**共享"当前状态" vs 共享"计划落点（intent）"，
> 在通信延迟下对协调结果有何差异？**
> 复现：`python3 tools/coord_prob.py --n 200000`（见输出 "C3: state vs intent" 段）。

---

## 1. 建模

沿用 C1 的二维脱靶模型（`report/coordination_probability.md`），聚焦**通信延迟**：

- **state-only**：B 对齐 A 的**当前状态**；延迟 `d` 内 A 以 `v_A` 运动 ⇒ 估计偏置 `b = v_A·d`。
- **intent**：A 广播**计划落点**（`/drone_a/intent`，含风漂移的预测落点）；B 对准该点 ⇒ **无延迟偏置**（`b=0`）。
- 证书闸：`exact`，`eff_r=0.25`，`ε=0.05`，`margin=0.05`，`σ_e=0.02`，`σ_track=0.02`。

> 关键：两者**阈值 T 相同**（T 只取决于 σ_m），差异在**脱靶均值**被延迟偏置平移 ⇒
> state 的真实脱靶分布偏离证书假设 ⇒ **保证被破坏**。

|---|---|---|---|---|---|---|

## 3. 结论（可写进论文）

1. **intent 对延迟不变**：无论 `v_A`、`d` 如何，intent 的成功率 ≈ 0.81、**条件捕获 = 1.000**
   —— 因为对准"计划落点"不引入 `v_A·d` 偏置。
2. **state-only 随 `v_A·d` 急剧退化**：v_A=1,d=0.2 时成功率 0.814→**0.199**（intent 仍 0.813，**≈4×**）；
   v_A=1,d=0.3 时 **0.021**；v_A=2,d=0.2 直接 0.000。
3. **state-only 破坏证书**：大偏置下 `条件捕获 < 1−ε`（v_A=1,d=0.3: 0.922；v_A=2,d=0.2: 0.344）；
   intent 始终 `=1.000` ⇒ **intent 是"保留概率保证"的信息形式**。
4. **定量收益**：intent 把**可认证的延迟预算**从 state 的 `d*≈(r_eff−margin−…)/v_A`（随 v_A 减小）
   扩展到"与 v_A 无关"——即**移动交付（v_A>0）时 intent 是必需项**。

## 4. 与代码/实验的对应

- 代码：A 广播 `/drone_a/intent`（`a_node._coord_tick`，预测落点 = 目标 + 风漂移）；
  B 用 `use_intent` 对准（`b_node` ALIGN）。
- SITL 局限：M6 竖直投放 **A 悬停（v_A≈0）且无风** ⇒ state ≈ intent，SITL 上差异≈0（空结果）；
  收益体现在**移动交付 / 有风**场景，故本报告用离线概率模型定量。
- 下一步（W3）：在 **M6-moving（v_A=0.5/1.0）** 中接入 intent 并做 SITL 对照，验证第 4 条。
