# M5 SITL 结果：难度扫描（2026-09-16）

环境：PX4-1.16 + px4_msgs v1.16.2 + 全系统 world；2 机（A=drone0 悬停释放，B=drone1 会合捕获）；
B 控制器 = acados 终端 MPC；载荷 = Gazebo 真实物理体（生成在停车位、释放时瞬移、ods 取状态）。

命令：`bash tools/sweep_sitl_difficulty.sh`（后台，结果 `/tmp/sweep_results.txt`）

## 结论

1. **温和场景可重复**：L0a/L0b 两次均捕获（d=0.27/0.40）。
2. **横向偏移不是瓶颈**：偏移 0.2→0.8 m 全部捕获（规划+MPC 预位能把 B 带到会合点）。
3. **真瓶颈是载荷下落速度（B 的末端俯冲）**：v_p≈2 m/s 全过；v_p≈4.9 m/s（A 从 4 m 投）时
   B 触发 failsafe（`Attitude failure (roll)` / `Compass 1`+`Battery unhealthy`），全部失败。
4. 失败机理：更快的载荷要求 B 更猛的俯冲，B 的姿态/EKF（叠加 drone1 固有传感器告警）撑不住 → failsafe。

## 下一步候选

- 修 B 的传感器/EKF 鲁棒性（mag 优先级、EKF 参数、或换无 mag 的 yaw 源）以推高边界；
- 或把"末端俯冲"做得更平滑（分段参考/更保守的接近），降低对 B 姿态的冲击；
- 或先把 M5-2（真实吸附）做掉，让"接住后带着飞"闭环，再回头扩边界。
