## 2. 一句话论点（Thesis）

> 在两机**相对状态不确定**、通信**延迟/丢包/时钟偏差**、交接是**离散事件**的条件下，
> 一种**"释放权威 + 意图共享 + 交接安全证书"**的协同策略，能够**可证明地**最大化捕获概率并保证不碰撞；
> 与之相对，常见的"单边（B 单方）/仅状态共享"协调会在不确定性下急剧退化。

---

## 3. 贡献清单（可检验）

- **C1（理论核心）** 相对脱靶的**概率模型**与**捕获概率下界**：
  给出 `P(capture) ≥ 1−ε` 的**释放证书**（把相对 σ、通信延迟 d、释放时刻 t_r 映射到脱靶分布），
  并给出 `k(ε)` 的显式形式。
- **C2（系统-通信）** **延迟补偿的释放时序协议**及其**时序误差上界**；
  对比 `direct`（B 单边）与 `authority`（A 作权威）。
- **C3（信息论视角）** **state vs intent** 的充分性对比：证明/量化"计划共享"在延迟下优于"状态共享"。
- **C4（协同规划）** A 的**速度/高度**与 B 机动的**联合（分布式）规划**，最大化捕获余量 / 最小化峰值加速度。
- **C5（安全）** **handover-CBF**：交接事件感知的分布式安全证书（不碰撞 + 捕获锥不变性）。
- **附加（实证）** 一个**开源基准与负结果集**（δ\*=0 等），提升可复现性与可信度。

> 现有工程（handshake / intent / σ 共享 / 安全层 / 基准）是这套贡献的**实现载体**。

## 4. 问题形式化（草稿）

**系统**：两台 UAV（A 携带、B 接收），载荷离手后做抛体运动。

- A：`ẋ_A = f_A(x_A, u_A)`；B：`ẋ_B = f_B(x_B, u_B)`（双积分器/简化动力学）。
- 载荷：`p_p(τ) = p_r + v_r τ + ½ g τ²`，`τ = t − t_r`。
- 通信：往返延迟 `d ~ D`、丢包 `p`、时钟偏差 `δ`；估计 `x̂_A, x̂_B`，协方差 `Σ`（或 σ）。
- 决策：释放时刻 `t_r`（由**释放权威**产生）+ 释放前机动 `{u_A(s),u_B(s)}`。

**捕获事件**（随机）：
```
E = { ‖p_B(t_c) − p_p(t_c)‖ ≤ r_eff  ∧  ‖v_B(t_c) − v_p(t_c)‖ ≤ v_c }
```

**优化问题**：
```
max_{t_r, {u_A,u_B}}   P(E | x̂_A, x̂_B, Σ, D)
s.t.  安全：d_min(A,B) ≥ d_safe ∀t   （CBF / 控制不变集）
      机动约束：|u| ≤ u_max, 能量/时间预算
```

**待证命题（C1 草案）**：
```
设相对脱靶 ~ N(μ(t_r), s(Σ,D)²)，则 t_r 的证书闸
    μ(t_r) + k(ε)·s(Σ,D) ≤ r_eff − margin
⇒ P(E) ≥ 1 − ε。
并讨论 e = 0（无不确定）时的最优释放时刻与该闸一致。
```

## 6. 实验协议

**指标**：捕获成功率（含 Wilson CI）、捕获时水平偏差、相对速度、`min‖A−B‖`、释放时延、弃投率、能量/峰值加速度。

**消融矩阵**（`tools/bench_coord.py` 已支持）：`authority/direct × state/intent × σ × delay × [CBF on/off]`。

**对比基线**：
- ① 预设/单边释放（direct）；
- ② 纯 MPC 拦截（无协调协议）；
- ③ 文献中的协同/捕获方法（复现 1–2 个）。

**仿真**：offline（大 N、秒级）+ SITL（中 N、含真实 PX4 闭环）。
**真机**：两机 + 相对感知，验证 C1/C2/C5（至少）；规模按 D2 定。
