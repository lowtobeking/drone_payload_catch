# 已证负结果（避免重走弯路）

> 负结果与正结果同样重要，它们界定了边界。**不要再投入这些方向**，除非前提改变。

1. **终端 MPC 未超过带解析前馈的 PD**（双积分器下 PD 前馈已近最优）。
   → 短下落时 MPC 反而"抄近路"偏离参考，捕获略松。

2. **去掉过冲/staged 参考反而更差**：min-energy 三次在时间充裕时会先爬升再俯冲，
   这是**反馈余量**的副产品；强行去除会用满 a_max、σ=0.15 成功率 8/10→6/10。默认保留 `cubic`。

3. **更好的估计器（KF）单独使用不提升端到端成功率**（真值基线同样 ~92%）。
   瓶颈是释放误差 + 动力学限幅，不是估计精度。

4. **敞口杯"变大"解决不了倾斜**：倾斜 >25° 即滚出，不如高摩擦平盘；保持/倾角需主动锁扣。

5. **横风下"猛下潜"是反效果**：拉长下落时间 → 风漂移更大。应取最小 gap、尽量不下潜。

6. **A 的小幅释放偏移与释放时刻 t_r 冗余**（`solve_cooperative` δ*=0）——协同价值在协议与
   A 的速度/高度配合，不在微调释放点。

7. **绝对 σ 当相对 σ 会让证书不可行**：需用相对模型（公共抵消 ρ / 相对传感器）。

8. **小托盘（30cm）在运动交接中会滑出**（物块继承水平速度）：运动交接需大托盘或主动锁扣。

9. **"老漏斗"其实是实心平顶盘**（gz cone roll=π）：不是空心导向漏斗。
